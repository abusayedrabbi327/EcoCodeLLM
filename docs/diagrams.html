Five-phase pipeline from problem input to energy-optimal code output

📥
Phase 1

Problem Input

User defines the task via a natural language prompt (Mode 1) or supplies an existing Python source file (Mode 2).

🤖
Phase 2

Code Generation / Parsing

Mode 1 calls GPT-4o for N code variants. Mode 2 parses source into an AST and detects energy anti-patterns.

  • Quadratic nested loops
  • String concatenation in loops
  • Unoptimised list operations
🧪
Phase 3

Correctness Validation

Every candidate runs in an isolated sandbox against a JSON test suite. Only passing candidates advance.

📊
Phase 4

Multi-Metric Profiling

Each valid candidate is profiled across three dimensions with subprocess isolation.

  • Time — perf_counter_ns
  • Memory — tracemalloc
  • Energy — RAPL / TDP estimate
🏆
Phase 5

TOPSIS Decision

Weighted multi-criteria scoring selects the energy-optimal candidate. Lower score = better energy efficiency.

Energy Weight
50%
Time Weight
35%
Memory Weight
15%

End-to-End Flowchart

Detailed execution flow with all decision branches and error paths

flowchart TD
    START(["START"]) --> LOADCFG["Load config.yaml\nParse CLI args"]
    LOADCFG --> MODESEL{{"Mode 1?"}}

    MODESEL -- Yes --> CHK_P{"Prompt\nprovided?"}
    CHK_P -- No  --> ERR1(["Error: prompt required"])
    CHK_P -- Yes --> M1_GEN["Call OpenAI API\nGenerate N variants"]
    M1_GEN --> CHK_API{"API OK?"}
    CHK_API -- No  --> ERR2(["Error: LLM failed"])
    CHK_API -- Yes --> LOAD_TC["Load JSON test cases"]
    LOAD_TC --> LOOP[/"For each candidate"/]
    LOOP --> SANDBOX["Execute in sandbox"]
    SANDBOX --> CHK_TEST{"Tests pass?"}
    CHK_TEST -- No  --> DISCARD["Mark invalid"]
    CHK_TEST -- Yes --> VALID["Add to valid pool"]
    DISCARD --> CHK_MORE{{"More?"}}
    VALID   --> CHK_MORE
    CHK_MORE -- Yes --> LOOP
    CHK_MORE -- No  --> CHK_EMPTY{"Pool empty?"}
    CHK_EMPTY -- Yes --> ERR3(["No valid candidates"])
    CHK_EMPTY -- No  --> PROFILE

    MODESEL -- No  --> CHK_FILE{"File\nprovided?"}
    CHK_FILE -- No  --> ERR4(["Error: file required"])
    CHK_FILE -- Yes --> READ_SRC["Read source file"]
    READ_SRC --> RUN_ORIG["Run original vs tests"]
    RUN_ORIG --> CHK_ORIG{"Passes?"}
    CHK_ORIG -- No  --> ERR5(["Original fails tests"])
    CHK_ORIG -- Yes --> DO_AST["Parse to AST"]
    DO_AST --> CHK_PARSE{"Parse OK?"}
    CHK_PARSE -- No  --> ERR6(["Syntax error"])
    CHK_PARSE -- Yes --> DETECT["Detect anti-patterns\nnested loops, str concat"]
    DETECT --> CHK_PATT{"Patterns\nfound?"}
    CHK_PATT -- No  --> NOOP["Code already efficient\nProfile original only"]
    NOOP --> END2(["Done"])
    CHK_PATT -- Yes --> REFAC["Apply AST refactoring"]
    REFAC --> RECON["Reconstruct source"]
    RECON --> VAL_RW["Validate rewritten code"]
    VAL_RW --> CHK_RW{"Passes?"}
    CHK_RW -- No  --> ROLLBK["Rollback to original"]
    ROLLBK --> END2
    CHK_RW -- Yes --> CMPPOOL["Comparison pool\nOriginal + Rewritten"]
    CMPPOOL --> PROFILE

    PROFILE["Profile all candidates\nisolated subprocesses"]
    PROFILE --> PT["Time Profiler\nperf_counter_ns"]
    PROFILE --> PM["Memory Profiler\ntracemalloc"]
    PROFILE --> PE["Energy Profiler\nRAEPL or TDP method"]
    PT & PM & PE --> PAGG["Aggregate ProfileResult\nper candidate"]
    PAGG --> PNORM["Min-Max Normalise\neach metric 0 to 1"]
    PNORM --> PTOPSIS["TOPSIS Score\nS = 0.50 E + 0.35 T + 0.15 M"]
    PTOPSIS --> PRANK["Rank candidates\nAscending score"]
    PRANK --> WINNER["Select Winner\nLowest TOPSIS score"]
    WINNER --> SAVE["Save optimized code\nand JSON report"]
    SAVE --> DONE(["END - Optimal Code Ready"])
